# SmartDocs AI MVP Scope

PDF dosyaları üzerinde yapay zeka destekli soru-cevap sistemi geliştirmek.

## MVP Özellikleri

- Login
- Register

### Doküman

- PDF yükleme
- PDF listeleme
- PDF silme

### AI

- PDF içeriğini okuma
- Chunking
- Embedding
- Semantic Search
- AI Chat

### Kaynak Gösterme

- Dosya adı
- Sayfa numarası
