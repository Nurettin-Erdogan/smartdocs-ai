# SQL Server migration arşivi

Bu dosyalar projenin önceki SQL Server sürümüne aittir. PostgreSQL sağlayıcısı SQL Server'a özgü veri tiplerini ve migration işlemlerini çalıştıramayacağı için dosyalar derlemeye dahil edilmez.

PostgreSQL için güncel migration'lar `backend/SmartDocsAI.API/Migrations` klasöründe oluşturulur.
