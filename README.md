# SmartDocs AI

## Proje Amacı

SmartDocs AI, PDF, Word, Excel ve TXT dosyalarını analiz ederek kullanıcıların doğal dilde soru sormasını sağlayan yapay zeka destekli doküman yönetim sistemidir.

## Özellikler

- Kullanıcı Girişi
- Doküman Yönetimi
- PDF Analizi
- AI Destekli Soru-Cevap
- Kaynak Gösterme
- Dashboard
- Raporlama
